# SkyPulse AI

SkyPulse AI is an AI-powered weather assistant built with Streamlit.

## Features

- Get current weather information for a city
- Displays temperature, humidity, and wind speed
- AI-generated weather report
- Simple and user-friendly interface
- Uses real-time weather data

## Technologies Used

- Python
- Streamlit
- Hugging Face
- Open-Meteo API
- Requests

## How It Works

1. User enters a city name.
2. The AI identifies the weather request.
3. The application retrieves the city's location.
4. Current weather data is obtained from Open-Meteo.
5. SkyPulse AI presents the weather information to the user.
